# سجل نشاط المستخدمين

الرابط: `/access-control/activity/`. السجل الأمني السابق `/access-control/logs/` باقٍ كما هو لمدير النظام الأعلى.

## الاستخدام والصلاحيات

في محرر الدور أو صلاحيات المستخدم توجد صفحة **سجل نشاط المستخدمين** وثلاث صلاحيات مستقلة: **عرض، تصدير Excel، تصدير PDF**. التصدير يتطلب العرض أيضًا. لا تُمنح هذه الصفحة تلقائيًا لأي دور حالي أو جديد. مدير النظام الأعلى يستطيع فتحها مباشرة. حساب يملك السجل فقط لا يستطيع إدارة الحسابات أو الأدوار. تظهر وصلة السجل في مكوّن التنقل الموجود، دون استبدال ترتيب الشريط الجانبي المخصص.

الحقول: التاريخ والوقت، المستخدم المنفذ واسمه وقت الحدث، القسم، العملية، السجل المتأثر، المناطق وقت الحدث، النتيجة، القيم السابقة والجديدة. الصف أو رابط التفاصيل يفتح نافذة مخصصة، وله رابط كامل بديل دون JavaScript. السجل للقراءة فقط، دون مسارات تعديل أو حذف.

الفلاتر: نص، منفذ، منطقة، قسم، عملية، نتيجة، تاريخ ووقت بداية ونهاية. الوقت بتوقيت الرياض الثابت UTC+03:00، وتحوّل الحدود إلى UTC في Python. اليوم النهائي مشمول، والساعة النهائية مشمولة حتى نهاية الثانية المختارة. تحديد ساعة يتطلب تحديد التاريخ المقابل. الفلاتر غير الصحيحة تعرض رسائل عربية ونتيجة فارغة؛ لا تتحول إلى تقرير شامل. ترقيم الصفحات يحتفظ بالفلاتر وحدّ أعلى ثابت للأحداث. التصدير يستخدم مكونات XLSX/PDF العربية ذات اتجاه RTL وألوان مكّن، ويشمل صفحات النتائج المصفّاة ضمن حدود التصدير الحالية للنظام.

## معنى التسجيل

- طلب GET ناجح لصفحة محمية، أو تفاصيل سجل، أو تنزيل مرفق، أو تصدير ناجح يسجّل حدثًا فعليًا واحدًا. HEAD، إعادة التوجيه، الصفحات غير الموجودة وصفحات التصدير الداخلية لا تُعد مشاهدات ناجحة.
- تسجيل المشاهدة يعني أن الخادم أعاد الاستجابة بنجاح، وليس إثبات قراءة كل محتواها. لا نسجل مدة القراءة أو حركات الماوس.
- الكتابات المؤكدة تسجّل بعد نجاح المعاملة، مع دمج الحفظ المتكرر لنفس السجل داخل الطلب، واستخدام سجل العمل الأصلي حين يتوفر. التراجع عن المعاملة لا يولّد حدث حفظ.
- توجد تغطية للإنشاء والتعديل والحذف وتغيير الحالة، ألوان حالات التطور، تخصيص التخصصات للقطاع، بنود البرنامج، علاقات الشراكات والمزودين، الرعاية والتمويل والتنفيذ والحساب الشخصي، وتسجيل الدخول والخروج. منع الوصول للمستخدم المسجل يولّد محاولة مرفوضة دون كشف اسم هدف غير مسموح.
- فتح نموذج أو نافذة تأكيد لا يثبت تعديل البيانات. أخطاء التحقق العادية ليست تعديلات. الطلبات المجهولة ومحاولات كلمة المرور الفاشلة تبقى ضمن نظام أمان الدخول الحالي؛ لم نستبدل Axes.

## المناطق والخصوصية

يحفظ كل حدث لقطة مستقلة لمناطق السجل وقت الحدث، وتضم جانبي نقل السجل بين المناطق. يجب أن يملك قارئ السجل المقيّد جميع مناطق الحدث، لمنع كشف قيم تاريخية من منطقة خارج نطاقه. الأحداث العامة والإدارية أو ذات المناطق غير الموثقة تاريخيًا تظهر فقط لمن يملك نطاق جميع المناطق. أسماء المستخدمين والمناطق في قوائم الفلترة تُستخرج من أحداث مسموحة فقط؛ تفاصيل الحدث والتصدير تستخدم نفس الحدود.

القيم المسجلة قائمة سماح صريحة. لا تُحفظ كلمات المرور أو تجزئاتها أو الجلسات أو رموز CSRF/التأكيد أو جسم الطلب أو رابط يحوي معاملات أو محتوى المرفقات. تغيير البريد والهاتف وكلمة المرور يظهر كعلامة تغيير دون قيمها. النصوص الحرة محدودة إلى 500 محرف، والقوائم إلى 200 عنصر؛ المرجع الأصلي يحتفظ بالتفاصيل الكاملة بحسب آليته السابقة. التصدير يتعامل مع قيم المستخدم كنص وليس صيغ Excel أو HTML.

## السجلات القديمة

الأمر `python manage.py import_user_activity` يستورد فقط ما هو موجود أصلًا في `SecurityAudit`, `ProviderAudit`, `AuditEvent`، ويحافظ على التوقيت، ولا يعدّلها أو يختلق مشاهدات قديمة. إعادة التشغيل آمنة عبر مفتاح مصدر فريد. الأدلة القديمة التي لا تثبت كل مناطق الجهات المرتبطة لا تُنسب إلى مناطق مفترضة، وتظهر بنطاق غير محدد للمخولين بجميع المناطق فقط.

## الحدود التشغيلية

هذا سجل على مستوى التطبيق، وليس دفترًا خارجيًا مقاومًا لتعديل مدير قاعدة البيانات. لا يلتقط SQL مباشرًا أو `QuerySet.update/bulk_create` خارجيًا لا يمر بواجهات المشروع أو يسجّل أثر عمل موجودًا. الأخطاء عند كتابة الحدث بعد نجاح المعاملة تُسجّل بواسطة آلية Django `on_commit(robust=True)` في سجل الخادم، دون إفشال عملية أعمال تم اعتمادها بالفعل. لا توجد إزالة تلقائية للسجلات في هذا التحديث.

الترحيل الإضافي الوحيد `access_control.0006_useractivity_activityregion_and_more`: جدول أحداث وجدول مناطق أحداث، وفهارس وقيود، وصفحة وثلاثة أذونات في الكتالوج. لا يغيّر منح الأدوار أو الحسابات أو التمويل أو حالات الأعمال.
