# تقرير إنجاز الشراكات (US-08)

## المسار والصلاحيات
- **المسار:** `/partnerships/reports/achievement/` (`partnerships:achievement_report`)
- **القائمة الجانبية:** تحت قسم **الشراكات** ← **إنجاز الشراكات**.
- **الصلاحيات:** `partnerships` (`view` للعرض، `export_xlsx` لتصدير Excel، `export_pdf` لتصدير PDF) مع تطبيق `RegionalPolicy` على مستوى المناطق.

## أبعاد التصفية والتجميع
- **السنة:** سنة بداية الشراكة أو تاريخ توقيع اتفاقياتها أو تاريخ الإنشاء.
- **المنطقة:** من المناطق الإدارية المعرّفة مسبقًا ضمن نطاق صلاحيات المستخدم فقط.
- **القطاع:** عبر عروض الشراكة (`PartnershipOffering.sector`).
- **النشاط / التخصص:** عبر تخصصات عروض الشراكة (`PartnershipOffering.specializations`).
- **الحالة:** حالة السجل (`نشطة` / `غير نشطة`)، مرحلة التطوير (`قدرة` / `رغبة` / `رعاية`)، أو حالة الاتفاقية (`AgreementOption.STATUS`).
- **نسبة الإنجاز:** تعتمد نفس حساب `agreement_clauses.models.mean_progress` المستخدم في بنود الشراكة والاتفاقيات دون استعلامات متكررة.
