# إحصائيات المهام (US-07)

## المسار والصلاحيات
- **المسار:** `/my-work/stats/` (`makken_mail:work_stats`)
- **الوحدة الصلاحية:** `work_assignments` (`view` لعرض التقرير، `export_xlsx` لتصدير Excel، `export_pdf` لتصدير PDF).
- **النطاق المناطقي:** يخضع التقرير لسياسة المناطق (`RegionalPolicy`) ونطاق السجلات المرتبطة؛ المدير المناطقي يرى الموظفين والمهام ضمن مناطقه فقط، ويرفض الخادم أي محاولة تصفية لمنطقة خارج نطاقه.

## آلية الاحتساب
- يعتمد التقرير على `makken_mail.WorkAssignment` مع دعم تعدد الموظفين المسند إليهم (`assignees`) والرجوع الآمن للحقل القديم (`employee`) دون تكرار احتساب المهمة للموظف نفسه.
- التصفية بالتاريخ (`من تاريخ` / `إلى تاريخ`) تعتمد على تاريخ إنشاء المهمة (`created_at`) بحدود اليوم المحلي.
- يعرض التقرير لكل موظف: إجمالي المهام، الجديدة، قيد العمل، المكتملة، الملغاة، المتأخرة، ومتوسط الإنجاز، مع صف إجمالي وبطاقات ملخص عليا وتصدير Excel / PDF.
